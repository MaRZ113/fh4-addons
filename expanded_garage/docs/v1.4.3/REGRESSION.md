# Regression

The same CLI rebuilt Suzuki 12000, Honda 12002 and RUF 12001 using the preserved IRs, original GameDB/manifest inputs and target shared resources. These are reference outputs from the existing production backend. The regression includes archive, manifest and GameDB verification and binary hash comparison. See `evidence/reproducibility.json` and `evidence/tests.txt`.

Honda 3477 and Acura 422 remain the established successful view controls. No shared baseline game file or Honda 3477 archive was changed during this work. The v1.4.3 package contains sanitized observations and hashes. Raw dumps, heap captures and autosaves remain local.
