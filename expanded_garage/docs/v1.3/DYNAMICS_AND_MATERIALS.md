# Dynamics and material scope

The existing FM4 gearbox ratios, final drive, mass, spring bounds, steering values and engine curves remain their measured or previously derived inputs. The shift compiler now accepts positive manufacturer gearbox evidence matched by physical traits. The Suzuki matches a 2.0-litre FWD six-speed manual with the expected wheelbase and six of seven signed-ratio magnitudes. Its FM4 third gear is 1.479, while the referenced Canadian table uses 1.379. The shift mode is corroborated and the FM4 ratio is preserved. Honda and RUF match their own factory documentation through the same data-driven profile matcher. [Suzuki US brochure](https://www.auto-brochures.com/makes/Suzuki/SX4/Suzuki_US%20SX4_2011.pdf) · [Suzuki Canada ratio table](https://www.centuryu.com/uploads/1/4/4/6/144698822/2012_sx4.pdf) · [Honda specifications](https://www.honda.co.jp/auto-archive/integra/3door/type-r2001/grade_data/) · [RUF model catalogue](https://www.no-speedlimit.it/downloads/World%20of%20RUF%202017%20-%20Edition%20VII.pdf)

Brake types map by the FM4 and FH4 semantic names. The target type defines rotor density. The external annulus of each source disc defines an axial thickness candidate. The two sides on each axle must agree. All three controls have two measured axles. The readback verifies density and measured thickness. Native torque limits, non-spinning brake mass, suspension progression and stops, anti-roll beam and driveline flex remain unresolved. Forty target fields remain unresolved per control, of which 27 are still classified as drive requirements. Assistance and final calibration remain listed separately.

The material contract distinguishes mandatory runtime surfaces, visibility surfaces, functional effects and fidelity. Each emitted draw names a checked FH4 library member. Tire and gauge needle materials use shared stock families. Emblems, calibration textures and appearance-only changes stay in fidelity or effects. Unclassified `misc` and `solid` draws still use an explicit opaque preview representation and block the visibility gate. Correct dirt, glass optics, badges, source textures and gauge emissive behavior remain tracked separately.

Independent structural results are in each `validation.json` under `conclusions`. A positive structural result does not imply ignition, suspension contact, steering control, accessory dispatch or persistent acquisition. The installer derives its decision from the mandatory gate states and checks the package and offline host preimages before a write.
